# 2026 年大模型与 Agent 工具演进盘点：模型月更时代，工具在卷什么

> 2026 年还剩两个多月，是时候停下来做一次盘点了。这一年，大模型的发布节奏从"季度更"提速到"月更"，仅 9 月就有六七款重量级模型扎堆亮相；Agent 工具则完成了从"单兵作战"到"团队协作"的形态跃迁，MCP、AGENTS.md、Skills 成了跨工具的通用三件套。这篇文章梳理三条线索：模型侧的进展、Agent 工具的演进，以及资本市场的真金白银如何为这场竞赛投票。

![2026 年大模型与 Agent 工具演进时间线](images/post-064/timeline.svg)

## 一、模型侧：今年的三条主线

### 1. 闭源旗舰进入"月更"节奏

三家的迭代密度肉眼可见地提高了：

- **Anthropic（Claude）**：4 月 Opus 4.7 登顶各大榜单；5 月推出 Opus 4.8 及推理增强版 Opus 4.8 Thinking；6 月发布 Sonnet 5；9 月更是连发 Fable 5.1 / Mythos 5.1，随后 Opus 5.5 于 9 月 22 日上线并成为 Claude Code 的默认 Opus 模型，支持 1M token 上下文，同期还有 Sonnet 5.5 补位中端。
- **OpenAI（GPT）**：4 月发布推理模型 GPT-5.5 thinking 与专业版 GPT-5.5 Pro；5 月补了轻量的 GPT-5.5 Instant；年中推出 GPT-5.6 家族，分 Sol / Terra / Luna 三档；9 月 GPT-6 Astra 成为 Codex 默认模型，同月又发了更便宜的 GPT-6 Sol 和 Luna。
- **Google（Gemini）**：2 月放出 Gemini 3.1 Pro 预览；5 月发布 Gemini 3.5 Flash 与视频模型 Gemini Omni；9 月的 Gemini 3.8 Flash 已经是四个月内的第四代 Flash——中端线的军备竞赛同样惨烈。

一个直观的感受：去年的盘点可以按"季度"组织，今年只能按"月"组织。

### 2. 开源与国产模型的贴身追赶

- **DeepSeek** 是全年最激进的开源力量：2 月发布推理特化的 V4；8 月 13 日推出 V4-Pro，直接以 Agent 场景为卖点，支持 1M 上下文并采用高峰/闲时差异化定价；9 月 10 日的 V4.1 Flash 把闲时价格打到每百万 token 输入 $0.15 / 输出 $0.60，权重以 MIT 协议开放。
- **Kimi K3** 以开源权重摸到前沿规模，8 月初登陆 GitHub Copilot；智谱 GLM-5.3 Flash、阿里 Qwen 3.5 也在年内完成更新，xAI 的 Grok 4.6 则在 8 月补上了高性能档位。

开源模型今年的角色变化值得注意：它们不再只是"平替"，而是开始成为工具链里被正式支持的一等公民——DeepSeek 官方宣布 OpenCode 完整支持 V4.1 Flash，智谱甚至在模型发布前就用 OpenCode 做匿名实测。

### 3. 三个结构性变化

比单个发布更重要的，是三个趋势的确立：

**"Agent 模型"成为独立品类。** 评测口径正在从基准分数转向长程任务的稳定性——能不能连续几十分钟不跑偏、能不能在几十轮工具调用后还记得最初的目标。DeepSeek V4-Pro 直接以 Agent 为定位，Anthropic 的发布节奏则明显围绕 Claude Code 的能力展开。模型为 Agent 优化，而不是为聊天优化，是今年最清晰的信号。

**1M 上下文成为标配。** Claude、Gemini、DeepSeek 的主力模型都到了 1M token。但上下文变长并没有杀死上下文工程——恰恰相反，塞得越多模型越容易"糊"，这直接催生了后面要讲的多智能体架构。

**定价分层，单任务成本数量级下降。** 峰谷分时定价普及，旗舰/中杯/轻量三档产品线成为标准打法。第三方机构 Artificial Analysis 的 Coding Agent Index 口径下，单个编码任务的成本大致是：

| 工具 + 模型 | 单任务成本 | 单任务耗时 |
| --- | --- | --- |
| Claude Code + Opus 5.5 | 约 $13.00 | 约 66 分钟 |
| Codex + GPT-6 Astra | 约 $7.47 | 约 29 分钟 |
| Codex + GPT-6 Sol | 约 $2.99 | 约 22 分钟 |

旗舰模型仍是质量天花板，但"够用"的门槛价已经降到一杯咖啡的钱。

## 二、商业化：资本用真金白银投票

技术叙事之外，今年的资本市场给出了同样清晰的信号。

### 1. Anthropic 与 OpenAI 的估值王座易主

OpenAI 3 月 31 日宣布完成 1220 亿美元融资，投后估值 8520 亿美元，当时是全球最贵的 AI 公司。但仅仅两个月后，Anthropic 在 5 月 28 日完成新一轮融资，估值冲到约 9650 亿美元，反超 OpenAI 登顶。

营收侧（据媒体报道的口径），Anthropic 的年化营收（ARR）从 5 月的约 470 亿美元快速增长到 7 月的约 650 亿美元，市场还传出其最快秋季启动 IPO、估值挑战 2 万亿美元的消息。Anthropic 反超的关键变量不是聊天产品，而是 **Claude Code 带动的企业级收入**——这解释了为什么所有厂商今年都在死磕 Agent 形态。

### 2. 国产模型的股价分化

1 月 8 日，智谱登陆港交所，成为"全球大模型第一股"，发行价 116.2 港元，开盘市值约 528 亿港元；一天后 MiniMax 上市，首日大涨 109%，市值突破千亿港元。到 4 月，智谱股价涨近 6 倍、市值超 3000 亿港元，MiniMax 累计涨幅超 475%——而同期阿里、腾讯年内跌幅在 17%–18%。市场在为"纯 AI 叙事"支付溢价，而没有旧业务包袱的新公司成了最大受益者。

不过叙事也要接受兑现的检验：7 月 8–9 日两只股票迎来上市后首次限售解禁，股价大幅回调（MiniMax 单日再跌 9.68%），此后高盛等机构反而转向唱好。一涨一跌之间，市场的定价逻辑从"有没有 AI 故事"切换到了"收入能不能跟上"。

### 3. 商业化数据说明了什么

把这些数字放在一起看，结论很直白：**模型公司的估值锚点已经从技术榜单切换到 ARR 的增长斜率**。而 ARR 增长最快的部分恰恰是 Agent 和编程场景，这反过来解释了模型侧的两个现象——为什么"Agent 模型"成了独立品类，以及为什么大家都在推 Coding Plan 订阅制。

## 三、Agent 工具：今年的五次演进

### 1. 形态演进：CLI 复兴 → 桌面端 → 云端异步 Agent

终端意外成为主战场。Claude Code、Codex CLI、OpenCode、Google 的 Antigravity CLI（由 Gemini CLI 过渡而来）都选择了命令行作为核心形态，原因很简单：Coding Agent 的最佳工作面就是文件系统和命令行。在此之上，桌面 App（多标签、多会话）补齐了可视化管理，而**云端异步 Agent** 成为今年的新物种——Copilot coding agent、Codex cloud、Claude Code 云端会话、Cursor cloud agents 都是同一个模式：你派发一个 Issue，它后台跑几十分钟，最后交付一个 PR。异步感，才是 Agent 区别于"补全工具"的本质。

### 2. 标准收敛：MCP / AGENTS.md / Skills 三件套

去年各家还在各搞一套，今年快速收敛：**MCP** 几乎所有主流工具都支持；**AGENTS.md** 被 Codex、OpenCode、Cursor、Kiro 读取，Claude Code 也可以用它替代 CLAUDE.md；**Skills** 格式则横跨 Claude Code、Codex、Cursor、Antigravity、Kiro。更有意思的是 Agent Client Protocol（ACP）的出现——6 月 2 日 Windsurf 更名为 Devin Desktop 后，可以通过 ACP 直接运行 Codex、Claude 等别家 Agent。围墙在拆，配置在变得可迁移。

### 3. 多智能体主流化：Subagent → Agent Team

单 Agent 开始过时。最轻量的形态是 Subagent——主 Agent 派出一组子 Agent，本质是上下文隔离加并行加速（1M 上下文塞太多反而变糊，这是 Subagent 流行的根本原因）；进一步的 Agent Team 则让模型自己写编排脚本，动态拉起几十甚至上百个子 Agent 并行干活、独立验证、交叉收敛。Claude Code 已经支持给同一会话里的每个子代理分别指定模型和推理预算，git worktree + 多 Agent 并行（Conductor、T3 Code 这类编排工具）也成了标配工作流。Anthropic 官方发布的《2026 Agentic Coding Trends Report》把"单 Agent 演进为协同团队"列为年度核心趋势，但同时给了一个清醒的注脚：开发者在约 60% 的工作中使用 AI，真正能"完全委托"的只有 0–20%——是协作，不是替代。

### 4. Harness 浮出水面

同一个模型，在不同 Harness（Agent 的运行框架）里跑，体感差好几个段位——差的是工程质量。今年 Harness 从幕后走到台前，还出现了两个标志性事件：Cognition 基于开源的 Kimi K3 后训练出自家模型 SWE-2，跑在 Devin 里；OpenAI 则把 Codex 的 Harness 开放成 Agents API，让开发者在自己的代码里调用。一句话总结：**模型是引擎，Harness 是整车**。买哪个工具，越来越取决于它的工程，而不只是它接入了哪个模型。

### 5. 范式与商业模式：SDD 与 Coding Plan

开发范式上，2026 年是 SDD（规范驱动开发，Spec-Driven Development）被主流工具全面采纳的一年——GitHub Spec Kit、AWS Kiro、Claude Code、Cursor、OpenSpec、BMAD、Antigravity 都上线了自己的 SDD 方案，核心命题从"要不要用 AI 写代码"变成"如何用 AI 写出能长期维护的代码"。商业模式上，按 token 计费基本退场，Coding Plan 订阅制成为主流：月费固定、额度内随便跑。成本焦虑这堵墙被拆掉后，开发者愿意问得更多、试得更猛——使用量的爆炸又反哺了模型的迭代速度，形成闭环。

## 四、对个人开发者的启示

把这三条线索合起来，今年的选型逻辑其实已经变了：

1. **从"哪个模型最强"变成"哪套工作流适合我"。** 终端双雄 Claude Code 和 Codex 各有拥趸，开源的 OpenCode、Cline 则保证了你随时可以带着配置换模型。先用同一个任务实测两三款，再决定把票投给谁。
2. **模型分配取代模型选择。** 最强配置往往是跨厂商的：旗舰模型（Opus 5.5 这个级别）做规划和评审，便宜模型（DeepSeek V4.1 Flash、GLM-5.3 Flash、Kimi K3）跑量。让实现者和评审者用不同厂商的模型，能抓住同家族评审漏掉的缺陷。
3. **投资于可迁移的资产。** AGENTS.md、Skills、MCP 配置是跨工具通用的。工具可以常换——今年的工具明年可能就改头换面——但你沉淀的工作流是自己的。

## 五、总结与展望

回头看这三年的主线：2024 年卷工具调用，2025 年卷工作流，2026 年卷的是 Agent 团队。模型层的能力通胀（月更、1M 上下文、Agent 特化）、Harness 层的工程竞争（异步、多智能体、标准收敛）、商业层的订阅制与估值重估，共同构成了今年的完整图景。

接下来两个多月值得盯的两件事：Anthropic 的 IPO 是否落地，那将是整个 Agent 经济的定价时刻；以及 Agent 团队的"组织化"——权限、审计、预算、问责这些真正的企业级问题，大概率是 2027 年的主题。当一支跑得好的 Agent 团队开始像一个真正的部门，管理它所需要的东西，也就不只是 prompt 了。
